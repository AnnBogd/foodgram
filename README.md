# Foodgram
Этот проект для тех, кто любит готовить и вкусно кушать :)
Здесь вы можете выкладывать свои рецепты, смотреть рецепты других кулинаров,
следить за обновлениями рецептов своих любимых авторов и подписываться на них.

## Архитектура проекта
Проект полностью контейнеризирован и состоит из следующих сервисов:
* **Backend** — API-приложение (Python)
* **Frontend** — клиентский интерфейс (React)
* **Database** — база данных (PostgreSQL)
* **Gateway/Nginx** — прокси-сервер для маршрутизации запросов

## Локальный запуск (Development)

Для запуска и отладки проекта локально вам понадобятся установленные **Docker** и **Docker Compose**.

### 1. Настройка переменных окружения
Клонируйте репозиторий и создайте локальный файл конфигурации `.env` из шаблона:
``` bash
cp .env.example .env
```
*Заполните файл `.env` вашими локальными данными (настройки подключения к БД, секретные ключи).*

### 2. Запуск контейнеров
Соберите и запустите все сервисы одной командой:
```bash
docker compose -f docker-compose.prod.yml up --build
```
После успешного старта приложение будет доступно на вашем компьютере по адресу: `http://localhost` (или `http://127.0.0.1`).

### 3. Применение миграций (если применимо)
Если вы запускаете проект впервые и нужно создать таблицы в базе данных, выполните команду внутри контейнера бэкенда:
```bash
docker compose-f docker-compose.prod.yml exec backend python manage.py migrate
```

## Развертывание на сервере (Deployment & CI/CD)

В проекте настроен автоматический пайплайн деплоя. 
При отправке кода в ветку `main` на сервере автоматически запускается сборка Docker-образов.

### Полезные команды для работы на сервере:

* **Посмотреть статус работающих контейнеров:**
  ```bash
  docker compose -f docker-compose.prod.yml ps
  ```
* **Проверить логи бэкенда в реальном времени (если что-то сломалось):**
  ```bash
  docker compose -f docker-compose.prod.yml logs -f backend
  ```
* **Перезапустить проект на сервере вручную:**
  ```bash
  docker compose -f docker-compose.prod.yml down && docker compose -f docker-compose.prod.yml up -d
  ```
